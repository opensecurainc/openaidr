# OpenAIDR shared helpers

`openaidr-common` supplies product/evidence vocabulary, pure policy pattern
compilation, and credential redaction. It contains no tenant application,
provider execution, private API protocol, or policy enforcement. The redaction
rule attribution is retained in `openaidr_common/secret-redaction.LICENSE`.

This directory is the Apache 2.0 source of the package. Development installs
it from here with `python -m pip install --no-deps -e packages/common` after
the application, as the [development guide](../../docs/guide.md#contribute-and-test)
shows; desktop and local-runtime builds install the reviewed wheel from
`dependencies/api-runtime/`.

Build from a clean source checkout:

```sh
python -m build packages/common
```

The package uses the repository's source-derived `YYYY.M.D+<commit>` version.
Its source archive includes the selected build record and a generated byte copy
of the canonical build metadata helper, so rebuilding the archive requires no
application checkout. The helper is build support only and is excluded from the
wheel. No second version algorithm is maintained here.
