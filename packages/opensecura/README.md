# opensecura

The [OpenSecura](https://opensecura.ai/) namespace on PyPI. OpenSecura builds
security tooling for AI coding agents, including
[OpenAIDR](https://github.com/opensecurainc/openaidr), which inventories AI
agents and tools, detects risky actions, and enforces guardrails at agent hooks.

This release reserves the package name. The OpenAIDR command line is published
as `aidr`. Until a functional release lands here, download the desktop app from
the repository's releases page.
