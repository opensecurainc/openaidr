# Application marks

Monochrome product marks from [Simple Icons](https://simpleicons.org/)
16.35.0, released under CC0 1.0. They identify the products named in the AI
Inventory; each mark remains the trademark of its owner. The dashboard paints
them with a CSS mask in the current text color so they follow the theme.
Applications without a mark here show their initial instead.

The AI Agent Costs model table also uses these marks. `openai.svg` and
`anthropic.svg` come from [Simple Icons 14.15.0](https://github.com/simple-icons/simple-icons/tree/14.15.0/icons),
under the same CC0 1.0 license. Models without a recognized provider use a
neutral chip icon.
